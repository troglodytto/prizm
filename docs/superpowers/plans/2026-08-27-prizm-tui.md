# prizm Phase 3 — The Charm Layer Implementation Plan

**Goal:** Add the interactive layer — a filterable picker, a checkbox multi-select, a form, an interactive `sync` resolver, and live `up` progress — without making a single existing command depend on a human being present.

**Architecture:** One `internal/tui` package holding a small component kit and a theme. Each component is a Bubble Tea model with a pure `update` method returning its own concrete type, so tests drive it by feeding `tea.KeyMsg` values and asserting on state — no pseudo-terminal, no golden screenshots. Commands call blocking helpers (`tui.PickOne`, `tui.PickMany`, `tui.Form`) that return plain Go values, so the call sites read like ordinary function calls rather than event loops. Every helper is guarded by `tui.Available()`; when there is no TTY the command falls back to its flag-driven path or errors with the exact flags to pass.

**Tech Stack:** Adds `github.com/charmbracelet/bubbletea` and `github.com/charmbracelet/bubbles`. Lip Gloss is already a dependency — Phase 1 Task 12 introduced `internal/style` for plain-text output — and this phase extends that palette rather than starting a second one.

**Spec:** `prizm-design-brainstorm-transcript.md` (the TUI picker, the fuzzy list, the styled `up` output), plus the interactive resolution described in Phase 2's sync design.

**Prerequisite:** Phases 1 and 2 complete.

## Global Constraints

- All Phase 1 and 2 constraints still hold.
- **The completion path never renders.** `__complete` must not construct a Bubble Tea program, read a terminal, or touch the cipher. Tab stays instant.
- **Every interactive surface has a non-interactive equivalent.** If a command can only be driven by a human, it cannot be scripted, and `up` in a shell alias or a CI job must keep working with no TTY at all.
- **`tui.Available()` gates every entry point.** It is false when stdin or stdout is not a terminal, when `PRIZM_NO_TUI` is set, or when `--no-tui` was passed. All three must work.
- **No TUI in the `up` write path by default.** `up` prints lines. Live progress is opt-in via `--live` (or automatic only when a TTY is present *and* the workflow covers enough repos to be worth it — see Task 8).
- **Components return values, not side effects.** A picker returns a string; it does not apply anything. Applying stays in the command.
- **Cancellation is a first-class result**, not an error to swallow: `tui.ErrCancelled` means the user pressed Esc, and callers exit quietly with status 0 rather than printing a stack of noise.
- **One palette.** `tui.Theme` is built from `internal/style`'s exported colours and marks. A workflow tagged `prod` is the same red in a picker badge, in `prizm status`, and in the confirmation before it applies — a viewer learns "red means production" once.

## Design: Where the TUI Is Allowed to Exist

prizm is a Tab-completion tool that occasionally opens a window. That ordering matters, because the temptation with Charm is to make everything a program, and that would ruin exactly the thing the spec optimised for first.

**The three interaction modes, and what each is for:**

| Mode | When | Cost |
| --- | --- | --- |
| Shell completion | You know what you want and are typing it | Must be < ~50ms; runs on every Tab |
| Plain text output | You are reading a result, or a script is | Zero |
| TUI | You need to *see a set* and choose from it | Takes over the terminal |

A surface earns a TUI only when the user genuinely cannot know the answer without seeing the options. That is a short list:

1. **`prizm` with no arguments.** You do not remember the workflow names. Completion can list them, but only if you already typed the group. A drill-down picker is strictly better here.
2. **Choosing repos for a workflow or a shared bag.** This is a *set*, not a value — checkboxes with a submit, not four sequential prompts.
3. **Resolving a sync conflict.** Phase 2 established that an edited derived value has two legitimate meanings. Presenting both, with the blast radius visible, is the whole reason the interactive layer exists.
4. **Stepping through history** (Phase 4's carousel).
5. **Watching a slow apply** — and only when it is actually slow, which in this phase means Docker in Phase 5 more than env writing.

Everything else — `status`, `ls`, `var`, `import`, `repair` — stays text. They are *reads* and *statements*, and text is faster to scan, greppable, and pipeable.

**What the fallback looks like.** Every interactive path has a stated flag equivalent, and the no-TTY error says it:

```
$ prizm add-workflow XYZ local < /dev/null
error: no terminal, so prizm cannot ask which repos this workflow covers
       pass --repos frontend,backend,auth (or --repos all)
```

That message is the contract: a human gets a checkbox list, a script gets a flag, and neither is a second-class path.

### Visual language

One theme, defined once, used everywhere. Lip Gloss adaptive colours so it reads on light and dark terminals.

```
┌ prizm ─ XYZ ────────────────────────────────────┐
│ Select a workflow                             │
│                                               │
│ ❯ local            frontend backend auth ai   │
│   qa-full          frontend backend auth ai   │  qa
│   frontend-only    frontend                   │  prod
│   debug-payments   frontend auth              │
│                                               │
│ / filter   ↑↓ move   ⏎ select   esc cancel    │
└───────────────────────────────────────────────┘
```

- **Tag colours are semantic and consistent**: `prod` red, `qa` amber, `local` green, untagged dim. The same palette is used by `status`, by the picker badge, and by the confirmation on a prod-tagged apply. A user should learn "red means production" once.
- **The help line is always visible.** No hidden keybindings; discoverability beats screen real estate for a tool used a few times a day.
- **Keys are the same everywhere**: `↑↓`/`kj` move, `/` filter, `space` toggle, `⏎` confirm, `tab` next field, `←→` step, `esc` cancel, `?` expand help. A component that needs a key not on this list is a component that is doing too much.

### Testing strategy

Bubble Tea models are state machines, so they are tested like state machines. Each model exposes a concrete-typed `update` and a `Result()`; the test feeds keys and asserts. This is why the kit is worth building rather than using `huh` directly for everything — the seam is what makes the behaviour testable.

```go
m := newPickManyModel("Repos", opts, nil)
m = m.update(tea.KeyMsg{Type: tea.KeyDown})
m = m.update(tea.KeyMsg{Type: tea.KeySpace})
m = m.update(tea.KeyMsg{Type: tea.KeyEnter})
// assert m.Result() == []string{"backend"}
```

No terminal is allocated, no golden files, and the tests run in CI.

```go
// Package tui is prizm's interactive layer. Every entry point is guarded by
// Available(), and every component returns a plain Go value so callers read
// like ordinary function calls rather than event loops.
package tui

import (
	"errors"
	"os"

	tea "github.com/charmbracelet/bubbletea"
	"golang.org/x/term"
)

// ErrCancelled means the user aborted. Callers should exit quietly, not noisily.
var ErrCancelled = errors.New("cancelled")

// disabled is set by --no-tui.
var disabled bool

// Disable turns the interactive layer off for this process.
func Disable() { disabled = true }

// reset restores the default state. Tests only.
func reset() { disabled = false }

// Available reports whether an interactive surface may be shown. It is false
// without a terminal on both ends, when PRIZM_NO_TUI is set, or after Disable().
func Available() bool {
	if disabled || os.Getenv("PRIZM_NO_TUI") != "" {
		return false
	}
	return term.IsTerminal(int(os.Stdin.Fd())) && term.IsTerminal(int(os.Stdout.Fd()))
}

// run drives a model to completion.
func run(m tea.Model) (tea.Model, error) {
	final, err := tea.NewProgram(m, tea.WithOutput(os.Stderr)).Run()
	if err != nil {
		return nil, err
	}
	return final, nil
}
```

Rendering to **stderr** is deliberate: it keeps stdout clean, so a command that ends by printing a result stays pipeable even when it showed a picker on the way.

**Interfaces:**
- Produces:

  - `tui.PickOne(title string, opts []Option) (string, error)` — blocking; returns the chosen `Value` or `ErrCancelled`.
  - `newPickOneModel(title string, opts []Option) pickOneModel` and `(pickOneModel).update(tea.Msg) pickOneModel`, `(pickOneModel).Result() (string, bool)` — the testable seam.

Filtering is substring, case-insensitive, over label and description. The spec asked for fuzzy; substring is the honest 90% and has no surprising ranking behaviour when you type three characters — and unlike fuzzy it never reorders the directory-relevance ordering the caller passed in, which matters because that ordering is the whole point of `rank`.

Create `internal/tui/pickone.go`:

```go
package tui

import (
	"fmt"
	"strings"

	tea "github.com/charmbracelet/bubbletea"
)

// Option is one selectable row.
type Option struct {
	Value string
	Label string
	Desc  string
	Tag   string
}

type pickOneModel struct {
	title     string
	options   []Option
	cursor    int
	filter    string
	filtering bool
	done      bool
	chose     bool
}

func newPickOneModel(title string, options []Option) pickOneModel {
	return pickOneModel{title: title, options: options}
}

// visible returns the options matching the current filter, in caller order.
func (m pickOneModel) visible() []Option {
	if m.filter == "" {
		return m.options
	}

	needle := strings.ToLower(m.filter)
	out := make([]Option, 0, len(m.options))
	for _, o := range m.options {
		haystack := strings.ToLower(o.Label + " " + o.Desc)
		if strings.Contains(haystack, needle) {
			out = append(out, o)
		}
	}
	return out
}

func (m pickOneModel) current() (Option, bool) {
	visible := m.visible()
	if m.cursor < 0 || m.cursor >= len(visible) {
		return Option{}, false
	}
	return visible[m.cursor], true
}

// Result reports the chosen value, and whether anything was chosen at all.
func (m pickOneModel) Result() (string, bool) {
	if !m.chose {
		return "", false
	}
	option, ok := m.current()
	if !ok {
		return "", false
	}
	return option.Value, true
}

func (m pickOneModel) Init() tea.Cmd { return nil }

func (m pickOneModel) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
	next := m.update(msg)
	if next.done {
		return next, tea.Quit
	}
	return next, nil
}

// update is the pure state transition, and the seam the tests drive.
func (m pickOneModel) update(msg tea.Msg) pickOneModel {
	keyMsg, ok := msg.(tea.KeyMsg)
	if !ok {
		return m
	}

	if m.filtering {
		return m.updateFiltering(keyMsg)
	}

	switch keyMsg.Type {
	case tea.KeyCtrlC, tea.KeyEsc:
		m.done = true
	case tea.KeyUp:
		m = m.move(-1)
	case tea.KeyDown:
		m = m.move(1)
	case tea.KeyEnter:
		if _, ok := m.current(); ok {
			m.done, m.chose = true, true
		}
	case tea.KeyRunes:
		switch keyMsg.Runes[0] {
		case 'k':
			m = m.move(-1)
		case 'j':
			m = m.move(1)
		case '/':
			m.filtering = true
		case 'q':
			m.done = true
		}
	}
	return m
}

func (m pickOneModel) updateFiltering(msg tea.KeyMsg) pickOneModel {
	switch msg.Type {
	case tea.KeyCtrlC:
		m.done = true
	case tea.KeyEsc:
		// Escape leaves the filter, not the picker.
		m.filter, m.filtering, m.cursor = "", false, 0
	case tea.KeyEnter:
		if _, ok := m.current(); ok {
			m.done, m.chose = true, true
		}
	case tea.KeyUp:
		m = m.move(-1)
	case tea.KeyDown:
		m = m.move(1)
	case tea.KeyBackspace:
		if m.filter != "" {
			m.filter = m.filter[:len(m.filter)-1]
			m.cursor = 0
		}
	case tea.KeyRunes, tea.KeySpace:
		if msg.Type == tea.KeySpace {
			m.filter += " "
		} else {
			m.filter += string(msg.Runes)
		}
		m.cursor = 0
	}
	return m
}

func (m pickOneModel) move(delta int) pickOneModel {
	next := m.cursor + delta
	if next < 0 {
		next = 0
	}
	if limit := len(m.visible()) - 1; next > limit {
		next = limit
	}
	if next < 0 {
		next = 0
	}
	m.cursor = next
	return m
}

func (m pickOneModel) View() string {
	var b strings.Builder

	b.WriteString(T.Title.Render(m.title) + "\n\n")

	visible := m.visible()
	if len(visible) == 0 {
		b.WriteString(T.Dim.Render("  no matches") + "\n")
	}
	for i, o := range visible {
		cursor := "  "
		label := T.Item.Render(o.Label)
		if i == m.cursor {
			cursor = T.Cursor.Render("❯ ")
			label = T.Selected.Render(o.Label)
		}

		row := fmt.Sprintf("%s%-20s %s", cursor, label, T.Dim.Render(o.Desc))
		if o.Tag != "" {
			row += "  " + TagStyle(o.Tag).Render(o.Tag)
		}
		b.WriteString(row + "\n")
	}

	b.WriteString("\n")
	if m.filtering {
		b.WriteString(T.Help.Render(fmt.Sprintf("filter: %s   ⏎ select   esc clear filter", m.filter)))
	} else {
		b.WriteString(T.Help.Render("↑↓ move   / filter   ⏎ select   esc cancel"))
	}
	return T.Frame.Render(b.String())
}
```

```go
package tui

import (
	"fmt"
	"strings"

	tea "github.com/charmbracelet/bubbletea"
)

type pickManyModel struct {
	title     string
	options   []Option
	selected  map[string]bool
	cursor    int
	filter    string
	filtering bool
	done      bool
	submitted bool
}

func newPickManyModel(title string, options []Option, preselected []string) pickManyModel {
	selected := make(map[string]bool, len(preselected))
	for _, v := range preselected {
		selected[v] = true
	}
	return pickManyModel{title: title, options: options, selected: selected}
}

func (m pickManyModel) visible() []Option {
	if m.filter == "" {
		return m.options
	}

	needle := strings.ToLower(m.filter)
	out := make([]Option, 0, len(m.options))
	for _, o := range m.options {
		if strings.Contains(strings.ToLower(o.Label+" "+o.Desc), needle) {
			out = append(out, o)
		}
	}
	return out
}

// selectedValues returns the ticked values in the caller's option order, so a
// workflow's repo list does not depend on the order the user clicked.
func (m pickManyModel) selectedValues() []string {
	var out []string
	for _, o := range m.options {
		if m.selected[o.Value] {
			out = append(out, o.Value)
		}
	}
	return out
}

// Result reports the selection, and whether it was submitted rather than cancelled.
func (m pickManyModel) Result() ([]string, bool) {
	if !m.submitted {
		return nil, false
	}
	return m.selectedValues(), true
}

func (m pickManyModel) Init() tea.Cmd { return nil }

func (m pickManyModel) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
	next := m.update(msg)
	if next.done {
		return next, tea.Quit
	}
	return next, nil
}

func (m pickManyModel) update(msg tea.Msg) pickManyModel {
	keyMsg, ok := msg.(tea.KeyMsg)
	if !ok {
		return m
	}

	if m.filtering {
		return m.updateFiltering(keyMsg)
	}

	switch keyMsg.Type {
	case tea.KeyCtrlC, tea.KeyEsc:
		m.done = true
	case tea.KeyUp:
		m = m.move(-1)
	case tea.KeyDown:
		m = m.move(1)
	case tea.KeySpace:
		m = m.toggleCurrent()
	case tea.KeyEnter:
		m.done, m.submitted = true, true
	case tea.KeyRunes:
		switch keyMsg.Runes[0] {
		case 'k':
			m = m.move(-1)
		case 'j':
			m = m.move(1)
		case '/':
			m.filtering = true
		case 'a':
			m = m.toggleAll()
		case 'q':
			m.done = true
		}
	}
	return m
}

func (m pickManyModel) updateFiltering(msg tea.KeyMsg) pickManyModel {
	switch msg.Type {
	case tea.KeyCtrlC:
		m.done = true
	case tea.KeyEsc:
		m.filter, m.filtering, m.cursor = "", false, 0
	case tea.KeyEnter:
		m.done, m.submitted = true, true
	case tea.KeyUp:
		m = m.move(-1)
	case tea.KeyDown:
		m = m.move(1)
	case tea.KeyBackspace:
		if m.filter != "" {
			m.filter = m.filter[:len(m.filter)-1]
			m.cursor = 0
		}
	case tea.KeySpace:
		m = m.toggleCurrent()
	case tea.KeyRunes:
		m.filter += string(msg.Runes)
		m.cursor = 0
	}
	return m
}

// toggleCurrent flips the row under the cursor *within the current filter*.
func (m pickManyModel) toggleCurrent() pickManyModel {
	visible := m.visible()
	if m.cursor < 0 || m.cursor >= len(visible) {
		return m
	}

	value := visible[m.cursor].Value
	next := make(map[string]bool, len(m.selected)+1)
	for k, v := range m.selected {
		next[k] = v
	}
	next[value] = !next[value]
	m.selected = next
	return m
}

// toggleAll selects everything visible, or clears it if all of it is selected.
func (m pickManyModel) toggleAll() pickManyModel {
	visible := m.visible()

	allOn := true
	for _, o := range visible {
		if !m.selected[o.Value] {
			allOn = false
			break
		}
	}

	next := make(map[string]bool, len(m.selected)+len(visible))
	for k, v := range m.selected {
		next[k] = v
	}
	for _, o := range visible {
		next[o.Value] = !allOn
	}
	m.selected = next
	return m
}

func (m pickManyModel) move(delta int) pickManyModel {
	next := m.cursor + delta
	if next < 0 {
		next = 0
	}
	if limit := len(m.visible()) - 1; next > limit {
		next = limit
	}
	if next < 0 {
		next = 0
	}
	m.cursor = next
	return m
}

func (m pickManyModel) View() string {
	var b strings.Builder

	b.WriteString(T.Title.Render(m.title) + "\n\n")

	for i, o := range m.visible() {
		cursor := "  "
		if i == m.cursor {
			cursor = T.Cursor.Render("❯ ")
		}

		box := "[ ]"
		if m.selected[o.Value] {
			box = T.Checked.Render("[x]")
		}

		b.WriteString(fmt.Sprintf("%s%s %-20s %s\n", cursor, box, o.Label, T.Dim.Render(o.Desc)))
	}

	b.WriteString("\n")
	if m.filtering {
		b.WriteString(T.Help.Render(fmt.Sprintf("filter: %s   space toggle   ⏎ submit   esc clear filter", m.filter)))
	} else {
		b.WriteString(T.Help.Render("↑↓ move   space toggle   a all   / filter   ⏎ submit   esc cancel"))
	}
	return T.Frame.Render(b.String())
}

// PickMany shows a checkbox list and returns the ticked values.
func PickMany(title string, options []Option, preselected []string) ([]string, error) {
	final, err := run(newPickManyModel(title, options, preselected))
	if err != nil {
		return nil, err
	}

	values, submitted := final.(pickManyModel).Result()
	if !submitted {
		return nil, ErrCancelled
	}
	return values, nil
}
```

```go
package tui

import (
	"fmt"
	"strings"

	tea "github.com/charmbracelet/bubbletea"
)

// Field is one short text input.
type Field struct {
	Key         string
	Label       string
	Placeholder string
	Value       string
	Required    bool
}

type formModel struct {
	title     string
	fields    []Field
	values    map[string]string
	focus     int
	err       string
	done      bool
	submitted bool
}

func newFormModel(title string, fields []Field) formModel {
	values := make(map[string]string, len(fields))
	for _, f := range fields {
		values[f.Key] = f.Value
	}
	return formModel{title: title, fields: fields, values: values}
}

// Result reports the entered values, and whether the form was submitted.
func (m formModel) Result() (map[string]string, bool) {
	if !m.submitted {
		return nil, false
	}
	return m.values, true
}

func (m formModel) Init() tea.Cmd { return nil }

func (m formModel) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
	next := m.update(msg)
	if next.done {
		return next, tea.Quit
	}
	return next, nil
}

func (m formModel) update(msg tea.Msg) formModel {
	keyMsg, ok := msg.(tea.KeyMsg)
	if !ok {
		return m
	}

	switch keyMsg.Type {
	case tea.KeyCtrlC, tea.KeyEsc:
		m.done = true

	case tea.KeyTab, tea.KeyDown:
		m.focus = (m.focus + 1) % len(m.fields)

	case tea.KeyShiftTab, tea.KeyUp:
		m.focus = (m.focus - 1 + len(m.fields)) % len(m.fields)

	case tea.KeyEnter:
		if missing := m.firstMissingRequired(); missing != "" {
			m.err = missing + " is required"
			return m
		}
		m.done, m.submitted = true, true

	case tea.KeyBackspace:
		m = m.edit(func(s string) string {
			if s == "" {
				return s
			}
			return s[:len(s)-1]
		})

	case tea.KeySpace:
		m = m.edit(func(s string) string { return s + " " })

	case tea.KeyRunes:
		runes := string(keyMsg.Runes)
		m = m.edit(func(s string) string { return s + runes })
	}
	return m
}

// edit applies fn to the focused field's value and clears any stale error.
func (m formModel) edit(fn func(string) string) formModel {
	next := make(map[string]string, len(m.values))
	for k, v := range m.values {
		next[k] = v
	}

	key := m.fields[m.focus].Key
	next[key] = fn(next[key])

	m.values = next
	m.err = ""
	return m
}

func (m formModel) firstMissingRequired() string {
	for _, f := range m.fields {
		if f.Required && strings.TrimSpace(m.values[f.Key]) == "" {
			return f.Label
		}
	}
	return ""
}

func (m formModel) View() string {
	var b strings.Builder

	b.WriteString(T.Title.Render(m.title) + "\n\n")

	for i, f := range m.fields {
		marker := "  "
		label := T.Item.Render(f.Label)
		if i == m.focus {
			marker = T.Cursor.Render("❯ ")
			label = T.Selected.Render(f.Label)
		}

		value := m.values[f.Key]
		shown := value
		if shown == "" {
			shown = T.Dim.Render(f.Placeholder)
		}
		if i == m.focus {
			shown += T.Cursor.Render("▏")
		}

		b.WriteString(fmt.Sprintf("%s%-18s %s\n", marker, label, shown))
	}

	if m.err != "" {
		b.WriteString("\n" + T.Err.Render(m.err) + "\n")
	}

	b.WriteString("\n" + T.Help.Render("tab next   ⏎ submit   esc cancel"))
	return T.Frame.Render(b.String())
}

// Form collects short text values.
func Form(title string, fields []Field) (map[string]string, error) {
	final, err := run(newFormModel(title, fields))
	if err != nil {
		return nil, err
	}

	values, submitted := final.(formModel).Result()
	if !submitted {
		return nil, ErrCancelled
	}
	return values, nil
}
```

```go
// scriptPicker answers picker prompts in order, recording what it was offered.
func (h *harness) scriptPicker(answers ...string) *[][]tui.Option {
	var offered [][]tui.Option

	i := 0
	h.app.PickOne = func(title string, options []tui.Option) (string, error) {
		offered = append(offered, options)
		if i >= len(answers) {
			return "", tui.ErrCancelled
		}
		answer := answers[i]
		i++
		return answer, nil
	}
	return &offered
}
```

```go
package cli

import (
	"errors"
	"fmt"

	"github.com/troglodytto/prizm/internal/rank"
	"github.com/troglodytto/prizm/internal/store"
	"github.com/troglodytto/prizm/internal/tui"
)

// canPick reports whether an interactive picker may be shown. A picker
// injected by a test counts, so the drill-down is testable without a terminal.
func (a *App) canPick() bool {
	return a.PickOne != nil && (tui.Available() || a.pickerInjected)
}

// browse drives group → workflow → apply. groupName skips the first step.
func browse(app *App, groupName string) error {
	if groupName == "" {
		chosen, err := pickGroup(app)
		if err != nil {
			return quietCancel(err)
		}
		if chosen == "" {
			return nil
		}
		groupName = chosen
	}

	g, err := app.mustGroup(groupName)
	if err != nil {
		return err
	}

	workflow, err := pickWorkflow(app, g)
	if err != nil {
		return quietCancel(err)
	}
	if workflow == "" {
		return nil
	}

	return app.withApplyLock(func() error {
		return applyWorkflow(app, g, workflow, false)
	})
}

func pickGroup(app *App) (string, error) {
	groups, err := app.Store.ListGroups()
	if err != nil {
		return "", err
	}
	if len(groups) == 0 {
		fmt.Fprintln(app.Out, "no groups yet — run `prizm init <name>`")
		return "", nil
	}

	if !app.canPick() {
		return "", listGroups(app)
	}

	// Same ordering completion uses, so the two never disagree.
	paths, err := app.Store.RepoPathsByGroup()
	if err != nil {
		return "", err
	}
	cwd, _ := app.Cwd()

	candidates := make([]rank.Candidate, 0, len(groups))
	byName := make(map[string]store.Group, len(groups))
	for _, g := range groups {
		byName[g.Name] = g
		candidates = append(candidates, rank.Candidate{
			Name: g.Name, Paths: paths[g.Name], UseCount: g.UseCount, LastUsedAt: g.LastUsedAt,
		})
	}

	options := make([]tui.Option, 0, len(groups))
	for _, name := range rank.Rank(candidates, cwd, app.Now()) {
		options = append(options, tui.Option{
			Value: name,
			Label: name,
			Desc:  fmt.Sprintf("%d repo(s)", len(paths[name])),
		})
	}
	return app.PickOne("Select a group", options)
}

func pickWorkflow(app *App, g store.Group) (string, error) {
	workflows, err := app.Store.ListWorkflows(g.ID)
	if err != nil {
		return "", err
	}
	if len(workflows) == 0 {
		fmt.Fprintf(app.Out, "%s has no workflows — run `prizm add-workflow %s <name>`\n", g.Name, g.Name)
		return "", nil
	}

	if !app.canPick() {
		return "", listGroup(app, g.Name)
	}

	options := make([]tui.Option, 0, len(workflows))
	for _, w := range workflows {
		repos, err := app.Store.WorkflowRepos(w.ID)
		if err != nil {
			return "", err
		}
		names := make([]string, 0, len(repos))
		for _, r := range repos {
			names = append(names, r.Name)
		}

		options = append(options, tui.Option{
			Value: w.Name,
			Label: w.Name,
			Desc:  joinOrNone(names),
			Tag:   w.Tag,
		})
	}
	return app.PickOne("Select a workflow — "+g.Name, options)
}

// quietCancel turns a user abort into a clean exit.
func quietCancel(err error) error {
	if errors.Is(err, tui.ErrCancelled) {
		return nil
	}
	return err
}

func joinOrNone(names []string) string {
	if len(names) == 0 {
		return "(no repos)"
	}
	out := names[0]
	for _, n := range names[1:] {
		out += " " + n
	}
	return out
}
```

```go
// applyWorkflow applies one workflow to every repo it covers. It is the shared
// body of `prizm up` and the interactive browse flow.
func applyWorkflow(app *App, g store.Group, workflowName string, dryRun bool) error {
	wf, err := app.Store.WorkflowByName(g.ID, workflowName)
	if err != nil {
		return fmt.Errorf("no such workflow %q in group %s", workflowName, g.Name)
	}

	repos, err := app.Store.WorkflowRepos(wf.ID)
	if err != nil {
		return err
	}
	if len(repos) == 0 {
		fmt.Fprintf(app.Out, "workflow %s covers no repos\n", wf.Name)
		return nil
	}

	failed := 0
	for _, repo := range repos {
		report, err := inspectRepo(app, g, wf, repo)
		if err != nil {
			failed++
			fmt.Fprintln(app.Out, style.Row(style.Fail, repo.Name, err.Error()))
			continue
		}
		if dryRun {
			reportDryRun(app, repo, report)
			continue
		}
		if report.Link == drift.Managed && !report.Diff.Empty() {
			fmt.Fprintln(app.Out, style.Row(style.Warn, repo.Name,
				fmt.Sprintf("%d local edit(s) will be overwritten — `prizm sync` first to keep them", driftCount(report))))
		}
		if err := applyRepo(app, g, wf, repo); err != nil {
			failed++
			fmt.Fprintln(app.Out, style.Row(style.Fail, repo.Name, err.Error()))
			continue
		}
		fmt.Fprintln(app.Out, style.Row(style.OK, repo.Name, "set ("+wf.Name+")"))
	}

	if dryRun {
		fmt.Fprintln(app.Out, "\n(dry run — nothing was written)")
		return nil
	}
	if err := app.Store.TouchGroup(g.ID, app.Now()); err != nil {
		return err
	}
	if failed > 0 {
		return fmt.Errorf("%d of %d repo(s) failed", failed, len(repos))
	}
	return nil
}
```

```go
package cli

import (
	"errors"
	"fmt"
	"strings"

	"github.com/troglodytto/prizm/internal/store"
	"github.com/troglodytto/prizm/internal/tui"
)

// errCancelledByUser signals a clean abort up to the command boundary.
var errCancelledByUser = errors.New("cancelled by user")

// canPickMany reports whether the checkbox list may be shown.
func (a *App) canPickMany() bool {
	return a.PickMany != nil && (tui.Available() || a.pickerInjected)
}

// canForm reports whether the text form may be shown.
func (a *App) canForm() bool {
	return a.Form != nil && (tui.Available() || a.pickerInjected)
}

// chooseRepos resolves which repos a workflow or bag covers.
//
// An explicit --repos always wins. Otherwise, when a terminal is available, a
// checkbox list opens with everything ticked — so pressing Enter reproduces
// the non-interactive default of "all repos" exactly, and unticking is the
// deliberate act. Without a terminal the default is unchanged.
func chooseRepos(app *App, g store.Group, list, purpose string) ([]int64, error) {
	if strings.TrimSpace(list) != "" {
		return resolveRepoIDs(app, g, list)
	}

	repos, err := app.Store.ListRepos(g.ID)
	if err != nil {
		return nil, err
	}
	if len(repos) == 0 {
		return nil, nil
	}

	if !app.canPickMany() {
		ids := make([]int64, 0, len(repos))
		for _, r := range repos {
			ids = append(ids, r.ID)
		}
		return ids, nil
	}

	options := make([]tui.Option, 0, len(repos))
	all := make([]string, 0, len(repos))
	byName := make(map[string]int64, len(repos))
	for _, r := range repos {
		options = append(options, tui.Option{Value: r.Name, Label: r.Name, Desc: r.Path})
		all = append(all, r.Name)
		byName[r.Name] = r.ID
	}

	chosen, err := app.PickMany(purpose, options, all)
	if err != nil {
		if errors.Is(err, tui.ErrCancelled) {
			return nil, errCancelledByUser
		}
		return nil, err
	}

	ids := make([]int64, 0, len(chosen))
	for _, name := range chosen {
		ids = append(ids, byName[name])
	}
	return ids, nil
}

// askWorkflowIdentity prompts for a workflow's name and tag.
func askWorkflowIdentity(app *App) (string, string, error) {
	if !app.canForm() {
		return "", "", fmt.Errorf("no terminal, so prizm cannot ask for a workflow name — pass it as an argument: prizm add-workflow <group> <name>")
	}

	values, err := app.Form("New workflow", []tui.Field{
		{Key: "name", Label: "Workflow name", Required: true},
		{Key: "tag", Label: "Tag", Placeholder: "prod / qa / local (optional)"},
	})
	if err != nil {
		if errors.Is(err, tui.ErrCancelled) {
```

```go
package tui

import (
	"fmt"
	"strings"

	tea "github.com/charmbracelet/bubbletea"
)

// ResolveRow is one decision the user has to make.
type ResolveRow struct {
	Key         string
	Detail      string
	Consequence string
	Choices     []string
}

type resolveModel struct {
	title     string
	rows      []ResolveRow
	chosen    []int
	cursor    int
	done      bool
	submitted bool
}

func newResolveModel(title string, rows []ResolveRow) resolveModel {
	return resolveModel{title: title, rows: rows, chosen: make([]int, len(rows))}
}

func (m resolveModel) choices() []int { return m.chosen }

// Result reports the chosen index per row, and whether it was submitted.
func (m resolveModel) Result() ([]int, bool) {
	if !m.submitted {
		return nil, false
	}
	return m.chosen, true
}

func (m resolveModel) Init() tea.Cmd { return nil }

func (m resolveModel) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
	next := m.update(msg)
	if next.done {
		return next, tea.Quit
	}
	return next, nil
}

func (m resolveModel) update(msg tea.Msg) resolveModel {
	keyMsg, ok := msg.(tea.KeyMsg)
	if !ok {
		return m
	}

	switch keyMsg.Type {
	case tea.KeyCtrlC, tea.KeyEsc:
		m.done = true
	case tea.KeyUp:
		m = m.move(-1)
	case tea.KeyDown:
		m = m.move(1)
	case tea.KeyLeft:
		m = m.cycle(-1)
	case tea.KeyRight:
		m = m.cycle(1)
	case tea.KeyEnter:
		m.done, m.submitted = true, true
	case tea.KeyRunes:
		switch keyMsg.Runes[0] {
		case 'k':
			m = m.move(-1)
		case 'j':
			m = m.move(1)
		case 'h':
			m = m.cycle(-1)
		case 'l':
			m = m.cycle(1)
		}
	}
	return m
}

func (m resolveModel) move(delta int) resolveModel {
	if len(m.rows) == 0 {
		return m
	}

	next := m.cursor + delta
	if next < 0 {
		next = 0
	}
	if next > len(m.rows)-1 {
		next = len(m.rows) - 1
	}
	m.cursor = next
	return m
}

func (m resolveModel) cycle(delta int) resolveModel {
	if len(m.rows) == 0 {
		return m
	}

	count := len(m.rows[m.cursor].Choices)
	if count == 0 {
		return m
	}

	next := make([]int, len(m.chosen))
	copy(next, m.chosen)
	next[m.cursor] = ((next[m.cursor]+delta)%count + count) % count

	m.chosen = next
	return m
}

func (m resolveModel) View() string {
	var b strings.Builder

	b.WriteString(T.Title.Render(m.title) + "\n\n")

	for i, row := range m.rows {
		marker := "  "
		if i == m.cursor {
			marker = T.Cursor.Render("❯ ")
		}

		b.WriteString(fmt.Sprintf("%s%-18s %s\n", marker, row.Key, T.Changed.Render(row.Detail)))

		choice := ""
		if len(row.Choices) > 0 {
			choice = row.Choices[m.chosen[i]]
		}
		line := "    " + T.Selected.Render("❮ "+choice+" ❯")
		if row.Consequence != "" {
			line += "   " + T.Warn.Render(row.Consequence)
		}
		b.WriteString(line + "\n\n")
	}

	b.WriteString(T.Help.Render("←→ change   ↑↓ move   ⏎ apply all   esc cancel"))
	return T.Frame.Render(b.String())
}

// Resolve asks the user to choose an option for each row.
func Resolve(title string, rows []ResolveRow) ([]int, error) {
	final, err := run(newResolveModel(title, rows))
	if err != nil {
		return nil, err
	}

	chosen, submitted := final.(resolveModel).Result()
	if !submitted {
		return nil, ErrCancelled
	}
	return chosen, nil
}
```

```go
// decide asks the user what to do about each item, or falls back to the
// non-interactive rules: actionable items apply, ambiguous ones are skipped.
func decide(app *App, plan syncplan.Plan) (map[string]syncplan.Decision, error) {
	decisions := make(map[string]syncplan.Decision, len(plan.Items))

	if !app.canResolve() {
		for _, item := range plan.Items {
			if item.Action == syncplan.Ambiguous {
				decisions[item.Key] = syncplan.DecideSkip
				continue
			}
			decisions[item.Key] = syncplan.DecideApply
		}
		return decisions, nil
	}

	rows := make([]tui.ResolveRow, 0, len(plan.Items))
	for _, item := range plan.Items {
		labels := make([]string, 0, 3)
		for _, choice := range item.Choices() {
			labels = append(labels, choice.Label())
		}

		consequence := ""
		if len(item.Consumers) > 0 {
			consequence = "also changes: " + strings.Join(item.Consumers, ", ")
		}

		rows = append(rows, tui.ResolveRow{
			Key:         item.Key,
			Detail:      itemDetail(item),
			Consequence: consequence,
			Choices:     labels,
		})
	}

	chosen, err := app.Resolve("Resolve edits — "+plan.Repo.Name, rows)
	if err != nil {
		if errors.Is(err, tui.ErrCancelled) {
			return nil, errCancelledByUser
		}
		return nil, err
	}

	for i, item := range plan.Items {
		decisions[item.Key] = item.Choices()[chosen[i]]
	}
	return decisions, nil
}

func itemDetail(item syncplan.Item) string {
	if item.Action == syncplan.DeleteFromOwningLayer {
		return "removed from the file"
	}
	if item.From == "" && item.To == "" {
		return "added in the file"
	}
	return item.From + " → " + item.To
}
```

```go
func applyPlan(app *App, wf store.Workflow, repo store.Repo, plan syncplan.Plan, decisions map[string]syncplan.Decision) error {
	for _, item := range plan.Items {
		switch decisions[item.Key] {
		case syncplan.DecideSkip:
			continue

		case syncplan.DecidePin:
			if err := app.Store.SetWorkflowRepoVarWithSource(
				wf.ID, repo.ID, item.Key, item.To, store.SourceSync,
			); err != nil {
				return err
			}

		case syncplan.DecideUpdateShared:
			if item.RefOrigin.SharedGroupID == 0 {
				return fmt.Errorf("%s: cannot update the shared value — it is not in a shared bag", item.Key)
			}
			if err := writeSharedValue(app, item.RefOrigin.SharedGroupID, item.RefName, item.To, repo.Name); err != nil {
				return err
			}

		case syncplan.DecideApply:
			if err := applyItem(app, wf, repo, item); err != nil {
				return err
			}
		}
	}
	return nil
}
```

```go
package tui

import (
	"fmt"
	"strings"

	"github.com/charmbracelet/bubbles/spinner"
	tea "github.com/charmbracelet/bubbletea"
)

// Step is one unit of work with a human-readable name.
type Step struct {
	Name string
	Run  func() (string, error)
}

type stepResult struct {
	detail string
	err    error
	ran    bool
}

type stepDoneMsg struct {
	index  int
	detail string
	err    error
}

type progressModel struct {
	title   string
	steps   []Step
	results []stepResult
	current int
	spinner spinner.Model
	done    bool
}

func newProgressModel(title string, steps []Step) progressModel {
	s := spinner.New()
	s.Spinner = spinner.Dot

	return progressModel{
		title:   title,
		steps:   steps,
		results: make([]stepResult, len(steps)),
		spinner: s,
		done:    len(steps) == 0,
	}
}

// Failed counts the steps that returned an error.
func (m progressModel) Failed() int {
	n := 0
	for _, r := range m.results {
		if r.err != nil {
			n++
		}
	}
	return n
}

func (m progressModel) Init() tea.Cmd {
	if m.done {
		return tea.Quit
	}
	return tea.Batch(m.spinner.Tick, m.runStep(0))
}

// runStep executes one step off the event loop and reports the result back.
func (m progressModel) runStep(i int) tea.Cmd {
	return func() tea.Msg {
		detail, err := m.steps[i].Run()
		return stepDoneMsg{index: i, detail: detail, err: err}
	}
}

func (m progressModel) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
	switch typed := msg.(type) {
	case stepDoneMsg:
		next := m.update(typed)
		if next.done {
			return next, tea.Quit
		}
		return next, next.runStep(next.current)

	case spinner.TickMsg:
		s, cmd := m.spinner.Update(typed)
		m.spinner = s
		return m, cmd

	case tea.KeyMsg:
		if typed.Type == tea.KeyCtrlC {
			m.done = true
			return m, tea.Quit
		}
	}
	return m, nil
}

// update is the pure transition the tests drive.
func (m progressModel) update(msg stepDoneMsg) progressModel {
	results := make([]stepResult, len(m.results))
	copy(results, m.results)
	results[msg.index] = stepResult{detail: msg.detail, err: msg.err, ran: true}

	m.results = results
	m.current = msg.index + 1
	m.done = m.current >= len(m.steps)
	return m
}

func (m progressModel) View() string {
	var b strings.Builder

	b.WriteString(T.Title.Render(m.title) + "\n\n")

	for i, step := range m.steps {
		switch {
		case m.results[i].ran && m.results[i].err != nil:
			b.WriteString(fmt.Sprintf("%s %-12s %s\n",
				T.Err.Render("✗"), step.Name, T.Err.Render(m.results[i].err.Error())))
		case m.results[i].ran:
			b.WriteString(fmt.Sprintf("%s %-12s %s\n",
				T.Added.Render("✓"), step.Name, T.Dim.Render(m.results[i].detail)))
		case i == m.current && !m.done:
			b.WriteString(fmt.Sprintf("%s %-12s\n", m.spinner.View(), step.Name))
		default:
			b.WriteString(fmt.Sprintf("  %s\n", T.Dim.Render(step.Name)))
		}
	}
	return T.Frame.Render(b.String())
}

// RunSteps runs steps in order with live feedback. It returns an error when
// any step failed, after running all of them.
func RunSteps(title string, steps []Step) error {
	final, err := run(newProgressModel(title, steps))
	if err != nil {
		return err
	}

	if failed := final.(progressModel).Failed(); failed > 0 {
		return fmt.Errorf("%d of %d step(s) failed", failed, len(steps))
	}
	return nil
}
```
